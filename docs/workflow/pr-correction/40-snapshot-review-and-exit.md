# Проверка снимка, вердикт и выход

Загружайте этот модуль только для состояний `C13`, `P01`, `B02`, `D03`, `P02`,
`C14`, `X01`, `X02` или `X03`.

Для `P02` дополнительно применяется
[доказательный шлюз](../shared/evidence-gateway.md). GitHub-контрольные действия
выполняет только пользователь.

## `C13` — Идентичность снимка PR

Исполнитель: агент.

Зафиксировать полные `base SHA`, `head SHA` и SHA-256 точной строки
`title + "\n" + body`. Изменение любого значения создаёт новый снимок и
обнуляет проверки прежнего снимка.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Удалённые base/head/title/body совпадают с зафиксированным снимком | `P01` | Агент |
| 2 | Не совпадает code/head и агент может исправить публикацию | `C12` | Агент |
| 3 | Не совпадают только метаданные title/body/readiness | `C06` | Агент |
| 4 | Снимок нельзя проверить из-за доступа или отсутствующих данных; сохранить `return_state=C13` | `B01` | Агент |

## `P01` — CI текущего commit

Исполнитель: GitHub; результат проверяет пользователь.

Результат: известен применимый CI именно для текущего `head SHA`. Ожидание CI
фиксируется как внешнее состояние, а не как неопределённая пауза.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | CI выполняется; сохранить `PENDING_EXTERNAL: CI` и событие возврата | `P01` | GitHub; следующий возврат инициирует пользователь |
| 2 | CI красный или неоднозначный | `C01` | Пользователь → агент |
| 3 | CI зелёный, текущий снимок уже явно делегирован применимому review-контуру | `P02` | Пользователь → исполнители review |
| 4 | CI зелёный, но PR draft или текущий снимок ещё не делегирован | `D03` | Пользователь |
| 5 | CI неприменим, текущий снимок уже делегирован review-контуру | `P02` | Пользователь → исполнители review |
| 6 | CI неприменим, текущий снимок ещё не делегирован | `D03` | Пользователь |
| 7 | Обязательная проверка отсутствует, а не просто ожидается; сохранить `return_state=P01` | `B02` | Пользователь или администратор |

## `B02` — Отсутствует обязательный CI

Исполнитель: пользователь или администратор.

Обязательная запись: отсутствующая проверка, владелец, событие восстановления и
`return_state=P01`.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Обязательная проверка восстановлена | `P01` | Пользователь или администратор |
| 2 | Требуется изменить правила или допустимый контур CI | `D01` | Пользователь |
| 3 | Пользователь отменил продолжение | `X03` | Пользователь |

## `D03` — Ready и делегация текущего снимка

Исполнитель: только пользователь.

Для code/runtime PR пользователь переводит draft в ready и передаёт тот же
снимок агенту и стороннему ИИ-ревьюеру. Для docs-only/process-only PR действует
выбранный пользователем контур проверки.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Draft переведён в ready и текущий снимок передан применимым ревьюерам | `P02` | Пользователь |
| 2 | Уже-ready PR повторно делегирован для нового текущего снимка | `P02` | Пользователь |
| 3 | Пользователь выбрал паузу; сохранить `return_state=D03` | `X03` | Пользователь |
| 4 | Пользователь отказался от продолжения | `X03` | Пользователь |

## `P02` — Проверка текущего снимка

Исполнители: агент и сторонний ИИ независимо для code/runtime; выбранный контур
для docs-only/process-only.

Агент фиксирует собственные findings до чтения внешних выводов. Проверка draft
является предварительной и не закрывает пакет после ready. Изменение снимка или
загрязнение проверки возвращает процесс к `C13`.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Проверка выполняется; сохранить `PENDING_EXTERNAL: REVIEW` и событие возврата | `P02` | Исполнители review; следующий возврат инициирует пользователь |
| 2 | Любая применимая проверка нашла новый сигнал | `C01` | Агент после получения результата |
| 3 | Все обязательные проверки текущего снимка завершены без замечаний | `C14` | Агент |
| 4 | Review, comments или threads недоступны; сохранить `return_state=P02` | `B01` | Агент |
| 5 | Проверки относятся к разным снимкам или загрязнены | `C13` | Агент |

## `C14` — Сводный технический вердикт

Исполнитель: агент.

Допустимые вердикты: `готово к merge`, `нужны правки`, `нужен выбор
пользователя`.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Доказательств достаточно, блокирующих проблем нет; вердикт `готово к merge` | `X01` | Агент |
| 2 | Подтверждено замечание, требующее исправления; вердикт `нужны правки` | `C01` | Агент |
| 3 | Нужен продуктовый выбор, решение по риску или объёму работ; вердикт `нужен выбор пользователя` | `D01` | Агент → пользователь |
| 4 | Для сводного вывода не хватает доказательств | `C02` | Агент |

## `X01` — Возврат в основной процесс: готово к merge

Следующий исполнитель: пользователь.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Пользователь успешно выполнил merge | `EXIT:main_process` | Пользователь |
| 2 | До merge появился новый технический сигнал | `C01` | Пользователь → агент |
| 3 | До merge изменился base/head/title/body | `C13` | Пользователь → агент |

## `X02` — Возврат в полный цикл ТЗ или новый stream

Исполнители: пользователь и агент по основному процессу.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Полное ТЗ согласовано для продолжения текущего PR без отдельного stream | `C07` | Пользователь → агент |
| 2 | Создан отдельный stream для блокирующего исправления; текущий PR сохраняет `return_state=C13` | `EXIT:main_process_stage_1` | Пользователь и агент |
| 3 | Изменение объёма работ отменено; зафиксировать режим остановки | `X03` | Пользователь |

## `X03` — Контролируемая остановка

Исполнитель: указанный владелец события возобновления; окончательную отмену
подтверждает пользователь.

Обязательная запись: `stop_mode=resumable_pause|final_cancellation`, причина и
владелец. Для возобновляемой паузы обязательны `return_state` и проверяемое
событие возобновления. Для окончательной отмены обязательны подтверждение
пользователя и проверка materialization.

| № | Проверяемый результат | Следующее состояние | Исполнитель перехода |
|---:|---|---|---|
| 1 | Возобновляемая пауза продолжается; событие ещё не наступило | `X03` | Указанный владелец |
| 2 | Событие наступило и условие разблокировки выполнено | `DYNAMIC:return_state` | Указанный владелец → агент |
| 3 | Окончательная отмена подтверждена; доказано отсутствие materialized результата | `EXIT:main_process_no_result_closure` | Пользователь → основной процесс |
| 4 | Окончательная отмена подтверждена; materialized результат существует или мог повлиять на внешний контур | `EXIT:main_process_materialized_route` | Пользователь → основной процесс |
| 5 | При окончательной отмене materialization установить нельзя; сохранить `return_state=X03` | `B01` | Агент |

No-result выход обязан пройти доказательство отсутствия результата, Terminal
outcome, Issue Closure, Spec Closure и cleanup. Materialized-выход возвращает
работу в обычное закрытие stream. Возобновляемая пауза closure не запускает.
