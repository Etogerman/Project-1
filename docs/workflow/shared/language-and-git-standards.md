# Язык и стандарты Git

Этот модуль обязателен для любой задачи, которая создаёт или меняет файл,
документацию, Git-состояние либо имя ветки. Он применяется также к docs-only и
agent-docs задачам без загрузки Laravel/runtime-правил.

## Язык

- Код приложения и комментарии в коде пишутся на английском языке.
- UI, агентская и пользовательская документация пишутся на русском языке.
- Общение, сообщения commit, заголовки и описания PR и человекочитаемые
  GitHub-комментарии ведутся на русском языке, кроме команд, путей, имён
  инструментов, API и терминов без точного перевода.
- Технический фрагмент на английском сопровождается русским объяснением риска
  и рекомендуемого действия.

## Имена веток

- Рабочая ветка использует префикс `codex/`.
- Остальная часть имени передаёт русский смысл через ASCII-транслитерацию.
- Кириллица в имени ветки запрещена.
- Имя коротко описывает один активный stream и не переиспользуется для другого
  несвязанного результата.

## Git-дисциплина

- До изменения проверяются точные worktree, ветка, base и незавершённые хвосты.
- Изменения разных рабочих копий не переносятся и не смешиваются молча.
- Commit, push, PR и внешняя публикация являются отдельными уровнями
  полномочий.
- История не переписывается, а worktree и ветки не удаляются без отдельного
  разрешения и проверки точной цели.
