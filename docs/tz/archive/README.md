# Архив ТЗ

В этой папке лежат закрытые технические задания проекта.

Сюда переносится ТЗ только после полного закрытия implementation stream:
- `staging` подтверждён
- `main` подтверждён
- production подтверждён, если входил в release flow
- критерии приёмки ТЗ выполнены

Активные рабочие ТЗ должны оставаться в `docs/tz/`.
